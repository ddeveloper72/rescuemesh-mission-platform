## Suggested Issue Labels

Create these labels for issue tracking:

**Type:**
- `bug` - Something isn't working
- `enhancement` - New feature or request
- `documentation` - Documentation improvements
- `scenario` - New mission scenario request
- `algorithm` - Algorithm improvement or testing

**Priority:**
- `priority: critical` - Critical issue requiring immediate attention
- `priority: high` - High priority
- `priority: medium` - Medium priority
- `priority: low` - Low priority

**Component:**
- `frontend` - Astro/TypeScript frontend
- `backend` - Django backend
- `simulation` - Simulation engine
- `api` - REST API
- `visualization` - Maps and 3D rendering
- `documentation` - Documentation

**Status:**
- `good first issue` - Good for newcomers
- `help wanted` - Extra attention needed
- `wontfix` - Won't be fixed
- `duplicate` - Duplicate issue

**Use Case:**
- `use-case: collapsed-building` - Collapsed building search
- `use-case: cave` - Cave rescue
- `use-case: flooded` - Flooded structure
- `use-case: industrial` - Industrial inspection
